# SWYNEX Internship Task 1: Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing a public Student Performance dataset using Python. The goal is to improve data quality and prepare the dataset for further analysis.

## Dataset
- **Name:** Student Performance
- **Source:** UCI Machine Learning Repository
- **Dataset URL:** https://archive.ics.uci.edu/dataset/320/student+performance

## Tools Used
- Python
- Pandas
- Jupyter Notebook or VS Code

## Data Cleaning Steps
1. Loaded the public dataset.
2. Inspected the dataset structure and data types.
3. Checked for missing values.
4. Identified and removed duplicate rows where present.
5. Standardized column names and text values.
6. Converted selected columns to appropriate data types.
7. Checked selected values for inconsistencies.
8. Exported the cleaned dataset for further analysis.
